FROM INTENT TO FEEDBACK

Make the rules part of the loop.

Requirements live next to your code, so every agent starts with the same expectations.

Reqfile.yaml01 / DEFINE 
# Say what must hold, and why.
reqfile: 1
code:
  - id: EXPLICIT_EXCEPTIONS
    must: No bare except clauses.
    why: Unexpected failures must surface.
    checks:
      - command:
          run: ruff check --select E722 .
          fast: true
          fix_hint: Catch a specific exception.
Agent terminal02 / CHECK → FIX 
$ reqfile check

EXPLICIT_EXCEPTIONS
  E722 Do not use bare `except`
  fix: Catch a specific exception.

# Your agent fixes the code and reruns.
$ reqfile check

1 check run. 0 violations. 0 errors.
